# UAV 間隔航測移動物件追蹤與定位不確定性：跨論文技術脈絡與研究缺口

## 核心結論
將傳統無人機影片追蹤推展到**「無人機間隔航測影像（Interval UAV Photogrammetric Imagery）的近即時移動物件追蹤」**時，現有 5 篇代表文獻各自補齊了拼圖的一塊，卻在關鍵交會點留下明確的研究缺口：
1. **2D 影像平面追蹤在視角大跳變下會失效**（`IoU = 0`），必須靠外觀引導（[[AMOT]]）、局部幾何特徵（[[LightGlue]]）或 3D 世界座標投影（[[MG-MOT]]、[[UCMCTrack]]）突破。
2. **光有地理投影還不夠，感測器誤差會製造「假位移」**：[[Yang2024-SeaYouLater]] 親證 UAV 元資料異常會造成世界座標漂移，[[Yi2024-UCMCTrack]] 證明透過投影協方差（誤差橢圓）與馬氏距離能大幅提升穩健性，但兩者皆未校準**跨曝光相對位移誤差相關性（$C_{ij}$）**，也未納入 DSM 地形起伏。
3. **「有沒有在動」不能只靠 2D 背景減除**：[[Liao2024-MoD2T]] 證明 2D ECC + 背景建模在相機快速移動下會崩潰（MVF1 `0.775 → 0.230`），且二元分類缺乏「未確定」緩衝與啟停回饋。
4. **核心研究缺口**：**如何將經校準的跨照片位移不確定性（[[Geolocation-Uncertainty]]）轉化為三態動靜與啟停證據（[[Motion-State-Estimation]]），並結合局部特徵剛體一致性（[[Local-Feature-Matching]]）與觀測機會，在有限發布延遲內完成可靠的近即時追蹤？**

## 從 5 篇文獻串聯出的教學簡報故事線（給零基礎讀者）

1. **問題引入（為什麼無人機「間隔拍照」很難追蹤？）**
   - 傳統影片 30 FPS 物件只動幾像素；航測等距間隔拍照雖然重疊 80%，但視角大跳變、目標位移大（`IoU = 0`），加上無人機 GPS/姿態誤差會讓「停著的車看起來也在動」。
2. **第一道解法：看外觀 vs. 看局部特徵**
   - 連續空拍可用 [[AMOT]]（[[Ma2026-AMOT]]）靠密集外觀回應圖把 ID 切換砍掉 72%；但在間隔航測大視角變化下，需要 [[LightGlue]]（[[Lindenberger2023-LightGlue]]）保留局部關鍵點幾何分布做剛體匹配。
3. **第二道解法：從 2D 影像跳到 3D 世界座標**
   - [[MG-MOT]]（[[Yang2024-SeaYouLater]]）示範用 UAV GPS 與雲台姿態投到世界地圖，讓海面長時程重辨識 IDF1 暴增 +17.2%——但也暴露元資料異常造成的座標漂移。
4. **第三道關鍵：把「定位誤差」畫成旋轉誤差橢圓**
   - [[UCMCTrack]]（[[Yi2024-UCMCTrack]]）教會我們用 Jacobian 誤差傳播取代固定距離門檻，在 `IoU = 0` 下依然精準關聯；進一步引入跨照片誤差相關性 $S_{ij} = \Sigma_i + \Sigma_j - C_{ij} - C_{ij}^\top$ 與 DSM 地形，就能校準航測假位移。
5. **第四道關鍵：它到底有沒有在動？（三態推論與近即時決策）**
   - [[MoD2T]]（[[Liao2024-MoD2T]]）點出動靜判斷的重要性與 2D 方法在劇烈運動下的失效；結合經校準的定位誤差，將判斷升級為「支持移動 / 支持近似靜止 / 未確定」三態，並依觀測機會在有限延遲內做出確認或短暫等待的近即時決策。

## 延伸分析與未解問題（Open Questions）
- **靜止參考地物的自動篩選**：如何在不依賴已知絕對控制點的情況下，穩定找出具可信對應的固定地物來校準 $S_{ij}$，且避免把待測目標誤當靜止參考？
- **物件高度與參考點一致性**：當不同航拍視角看到車輛不同側面或車頂時，如何避免 bounding box 中心投影到 DSM 產生的視差假位移？
- **近即時等待策略的量化門檻**：在有限發布時限下，如何定量評估「再等下一張曝光」的資訊增益是否值得延遲發布？
